# Roadmap

## Fase 0: Base De Produto

Status: parcialmente implementada.

- [x] Spec-driven design inicial.
- [x] Correcao de cortesia Pro expirada.
- [x] Reposicionamento inicial da landing.
- [x] Raio-X Financeiro deterministico.
- [x] Preco low ticket de referencia.

## Fase 1: Diagnostico Mais Forte

Objetivo: tornar o Raio-X confiavel e util com poucos dados.

- [ ] Onboarding financeiro.
- [ ] Estado vazio orientado por tarefas.
- [ ] Classificacao financeira expandida.
- [ ] Detector de cartao, emprestimo e parcelamento.
- [ ] Explicacao de risco por perfil.

## Fase 2: Plano De Recuperacao

Objetivo: transformar diagnostico em execucao.

- [ ] Tela Plano de Recuperacao.
- [ ] Etapa atual calculada por regra.
- [ ] Meta de folga mensal.
- [ ] Meta de reserva minima.
- [ ] Checklist mensal.
- [ ] Progresso historico.

## Fase 3: Dividas E Credores

Objetivo: tratar dividas como entidade propria.

- [ ] Cadastro de dividas.
- [ ] Status de negociacao.
- [ ] Simulacao de quitacao.
- [ ] Prioridade por juros, risco e valor.
- [ ] Historico de acordos.

## Fase 4: IA Mais Personalizada

Objetivo: usar IA onde ela realmente ajuda.

- [ ] Plano textual gerado com base no diagnostico.
- [ ] Sugestoes por perfil de causa raiz.
- [ ] Analise de recorrencias.
- [ ] Explicacao de "por que este passo agora".
- [ ] Cache e controle de custo por feature.

## Fase 5: Relatorios E Retencao

Objetivo: mostrar evolucao e manter consistencia.

- [ ] Relatorio mensal de recuperacao.
- [ ] Comparativo de saldo real mes a mes.
- [ ] Marcos: primeiro mes positivo, reserva inicial, divida quitada.
- [ ] Emails ou notificacoes leves.

## Ordem Recomendada De Implementacao

1. Onboarding.
2. Plano de Recuperacao.
3. Entidade de dividas.
4. Classificacao expandida.
5. IA personalizada.
6. Relatorios de recuperacao.
